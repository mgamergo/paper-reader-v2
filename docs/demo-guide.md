# Record feature clips for later sharing

Prepare each clip with the paper already imported and indexed. Hide personal library titles, user names, provider keys, and account details. Record the reader at a legible zoom. Keep the clip between 15 and 30 seconds, and save it privately. Nothing in this guide posts to X or changes repository visibility.

Use the personal introduction once: "English is my second language. Reading papers meant searching every few sentences, so I built explanations that understand the paper."

## Explain a term in its own sentence

Open two papers from different fields that use the same word. Select the first occurrence, choose **Explain**, and show the sentence and field beside its passage links. Switch to the second paper and repeat. End with the two different source-backed meanings visible.

Use a configured real model for the contrasting meanings. In offline mode, label the clip "deterministic extractive demo" and show only supported source quotations. Do not present the mock as a semantic model.

## Read English beside a native explanation

Set Hindi, Telugu, or Marathi in the reader preferences. Select one difficult sentence, choose **Explain**, and show the English sentence beside its native explanation. Click one passage link so the exact evidence flashes in the paper. Override the language for the next explanation without changing the default.

Record this clip only after a real provider passes language review. The mock intentionally reports that translation is unavailable. Do not replace its output with invented translated API responses for a product demo.

## Change the paragraph difficulty

Select a dense paragraph. Move the difficulty slider, request the rewrite, and open one retained technical term's definition. Finish by jumping from the explanation to its original passage.

Use a verified real provider for a rewritten paragraph. Offline mode can show the slider and request mechanics, but cannot establish simplification quality.

## Turn a new term into a flashcard

Explain a source-defined term and choose **Save term**. Open the personal glossary, review the source quote, and start flashcards. Reveal the answer and grade the card. End with the next review date visible.

Use a term whose definition is supported by the paper. Show the extracted source definition honestly when using the mock.

## Preview a citation without losing your place

Hover or focus an in-text reference. Pause on the cited work's title, authors, year, and available abstract. Show the linked document preview, choose **Add to library**, and return to the same page and zoom. Use an open-access paper whose actual PDF link resolves.

## Understand a figure or equation

Hover an in-text figure or equation reference. Show its original-page preview, open the source, and select **Explain this figure** or **Explain this equation**. End on the supported explanation and its source link.

A text-based explanation uses captions and extracted equation text. Describe an image interpretation only if a separately verified vision provider supplies it.

## Ask a grounded question

Ask about the paper's method. Show the answer's sentence-level citations, click one, and let the source passage flash. Ask an unrelated question and leave the clear unsupported-answer message visible. This clip works with the deterministic mock when the paper contains explicit answers.

## Inspect how retrieval reached the answer

Open retrieval debug after a grounded question. Expand a result's score details. Show BM25, TF-IDF, dense retrieval, RRF, and reranking as separate stages, then open the top retrieved passage. Label offline hash embeddings when that provider is active.

## Compare papers and keep your reading place

Open a second paper in split view. Navigate each pane independently, add a source note, and return to the library. Reopen the first paper to show its persisted page. Keep both paper titles visible so the independence is clear.

## Read with the keyboard

Press **?** to reveal the actual shortcut list, remap one command, and run it. Close the sheet, use **j**, **k**, and **/**, and then open the command palette. End by switching to a reading theme. Restore the remapping before recording another clip.
